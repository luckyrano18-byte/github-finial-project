# Simple Interest Calculator

This project is a simple interest calculator that calculates the simple interest based on the principal amount, annual interest rate, and time period.

This project was updated as part of my GitHub learning assignment.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal = Initial amount of money
- Rate = Annual interest rate
- Time = Time period in years

## Example

If the principal is $1000, the interest rate is 5%, and the time is 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = $100

## Usage

Enter the principal amount, interest rate, and time period to calculate the simple interest.
